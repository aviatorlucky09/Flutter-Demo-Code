# Framebright Demo Flutter App

This repository contains a demonstration Flutter application showcasing modular development suitable for Framebright's kid-safe internet platform.

## 📱 Modules Included

### 1. Safe Browser
A secure WebView module that restricts navigation to pre-approved (whitelisted) child-safe domains only.

- Displays a safe homepage (`kids.nationalgeographic.com`)
- Blocks all non-whitelisted URLs

### 2. Profile & Avatar Builder
A friendly interface for kids to create their profile.

- Enter name with safe character handling
- Choose from pre-selected avatar icons
- Displays live preview of name and avatar

### 3. Content Feed
A scrollable feed of educational cards.

- Static list of interactive content titles (e.g., facts, quizzes)
- Designed to be extended into dynamic or API-fed content

## 🚀 Getting Started

1. Clone this repository
2. Run `flutter pub get`
3. Launch using `flutter run`

## 🧰 Tech Stack

- Flutter & Dart
- WebView Flutter plugin
- Material Design widgets
- Modular file structure

## 📦 Purpose

This demo is created to demonstrate coding style, modular development, and user-focused design for Framebright's technical leadership.
